# Skill Matcher

**Skill Matcher** — система анализа вакансий и навыков, предназначенная для построения профилей профессий и генерации персонализированных образовательных роадмапов. 

Проект собирает данные о вакансиях, нормализует навыки, выявляет ключевые компетенции и строит образовательную траекторию с помощью связи с курсами Stepik и Udemy.

## Структура проекта

- **`src/`** — Исходный код системы
  - `skills_taxonomy.py` — Таксономия навыков: синонимы, стоп-слова, мэппинг фреймворков и кластеризация.
  - `roadmap.py` — Логика рекомендательной системы: построение профилей и генерация роадмапа.
  - `courses.py` — Модуль для работы с датасетами курсов и их обработки.
  - `vectorizer.py` — Векторизация и NLP-задачи (поиск, сопоставление навыков).
- **`notebooks/`** — Jupyter-ноутбуки для экспериментов (векторизация, матчинг, анализ курсов).
- **`data/`** — Данные парсинга (вакансии, парсинг с Udemy/Stepik).
- **`models/`** — Сохранённые профили профессий и другие артефакты.

## Основные возможности

1. **Нормализация навыков**: Приведение "шумных" названий навыков к единой таксономии (например, "react.js" и "reactjs" → "react").
2. **Построение профиля профессии**: Автоматическое выделение Top-N ключевых навыков по категориям (языки программирования, базы данных, облачные сервисы и т.д.) на основе свежих данных (с учётом временного затухания `time_weight`).
3. **Генерация роадмапа (Roadmap)**: Сравнение текущего стека пользователя с профилем профессии и выдача рекомендаций, какие навыки необходимо прокачать.
4. **Матчинг образовательных курсов**: Рекомендация курсов для закрытия пробелов в навыках.

## Установка и использование

1. Клонируйте репозиторий:
   ```bash
   git clone <URL_репозитория>
   cd skill_matcher
   ```

2. Установите зависимости через `uv` или систему на ваш выбор (указаны в `pyproject.toml`):
   ```bash
   uv pip install .
   # Или установите дополнительные зависимости для работы, такие как sklearn, pandas, и тд.
   ```

3. Пример генерации профиля:
   Смотрите примеры в папке `notebooks/matcher.ipynb`.
